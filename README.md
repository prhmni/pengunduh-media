# Pengunduh Media Cepat

Aplikasi web modern berbasis Flask dan yt-dlp untuk mengunduh audio (MP3) maupun video (MP4) langsung lewat peramban.

## Fitur
* Tampilan modern dan bersih dengan Tailwind CSS.
* Unduh format Video (MP4) atau Audio (MP3).
* Notifikasi proses langsung di layar.

## Prasyarat
* Python 3
* FFmpeg

## Cara Menjalankan
1. Pasang dependensi:
   pip install -r requirements.txt
2. Jalankan server:
   python app.py
3. Buka peramban di http://127.0.0.1:5000
